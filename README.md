# maimai 自动写谱器（纯浏览器）

给一首歌的 `track.mp3` + BPM + offset，直接生成一张可以直接导入 AstroDX / simai 的
`maidata.txt`。**全部在浏览器里完成**，不上传任何文件，不需要 Python、不需要服务器。

打开网页 → 拖入 mp3 → 填 BPM 和 offset → 生成 → 保存 `maidata.txt`。

## 怎么用

1. 打开 Pages 地址（或本地双击 `index.html`）
2. 点「选择文件夹」，选中含有 `track.mp3` 的那个歌曲文件夹
   （也可以直接把 mp3 拖进页面）
3. 填 BPM、offset（offset = 第一小节的第一个拍点相对音频开头的秒数，可以是负数）
4. 点「生成」，谱面会显示在下面，并且可以：
   - 直接写入该文件夹的 `maidata.txt`（会先问你确认，不覆盖已存在的文件）
   - 或者下载成文件
5. 点「预览播放」可以在网页里看谱面试打效果

浏览器要求：Chrome / Edge 86+（用到了 File System Access API 来写文件）。
Safari / Firefox 只能下载文件，不能直接写入文件夹。

## 它是怎么工作的

**不是**用一个神经网络逐格预测音符。真正的生成流程是**检索**：

1. 从 345 首官方 Lv.12+~13+ 谱面里，按小节切出 **26,977 个「配置模板」**
   （一个小节里音符落在哪几个十六分位置、用哪几个键、是 tap/hold/星星、时长多少）
2. 对新歌的每个小节，算出它的 **48 维音频描述子**
   （16 个十六分位置 × 3 个频带的 band-flux 峰值）
3. 用余弦相似度在模板库里找最像的几个，加上三个偏好项后选一个：
   - **DX 世代加分**（DX 之后的谱面手感更现代）
   - **密度加分**（忙碌的小节偏好音符更饱满的配置，避免照抄官谱的休息小节）
   - **BPM 相近加分**（200 BPM 的十六分连打和 120 BPM 的不是一回事）
4. 同一份配置全曲最多用 **2 次**
5. 套用时按 20% 的概率做**镜像/旋转**（左右、上下、45°），避免完全照抄
6. 最后过一遍**微调与可玩性检查**：
   - 极安静的小节（响度 < 全曲中位数 35%）**不写音符**
   - 有声音的小节至少补到 2 个音符，不留白
   - 每小节最多删 2 个 / 加 1 个音符用来贴歌
   - 星星独占一格；wifi 星星（`w`）算两只手；双押必须是合法手型
   - 同一键 12 格内不重复、起始拍间距 ≥ 6 格
   - **绝赞星星一律不生成**（太难打）

生成结果的双押率、按键分布、星星比例、绝赞比例都和官方谱面的统计接近
（配置相似度 0.78，官方谱面互相比较的上限是 0.80）。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 写谱页面 |
| `play.html` | 谱面预览播放器 |
| `js/chartnet.js` | 检索 + 解码 + 可玩性检查 + simai 输出 |
| `templates.js` | 26,977 个官谱小节模板 + 48 维音频特征（5.3 MB） |
| `weights.js` | 一个辅助的神经网络权重（用于回退路径，3.4 MB） |

`templates.js` 有 5 MB 左右，第一次打开会稍微等一下（之后浏览器会缓存）。

## 关于曲谱数据

`templates.js` 里的配置来自 maimai 官方谱面。本项目只用于**非商业的学习与研究**，
不包含任何音频、图片或游戏本体资源 —— 你提供自己的 mp3。
如果你要 fork 后商用，请自行删除 `templates.js` 并重新训练。

## 本地跑

不需要构建，直接双击 `index.html` 就行。
（`file://` 下写文件功能不可用，只能下载；要完整功能请用任意静态服务器，
例如 `python -m http.server`。）
